# Mawa Homebazar BD (Client)

Frontend for **Mawa Homebazar BD** — a variety-products online marketplace in Bangladesh.

Built with **Next.js 16**, **React 19**, **Tailwind CSS v4**, and **Redux Toolkit / RTK Query**.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

> Configure the API base URL in `.env.local` (`NEXT_PUBLIC_API_URL` — e.g. `http://localhost:5000/api`).
